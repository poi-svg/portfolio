# 郭缙 · 个人作品集

一个杂志排版风格的个人作品集网站，用于展示个人介绍、项目经历与联系方式。

## 项目简介

页面以「杂志版面」为设计思路：米白底色搭配墨黑文字与单一橘红强调色，衬线大标题配合无衬线正文。项目区没有采用常见的卡片网格，而是为每个项目分配独立版面，通过图文比例、疏密节奏的变化形成阅读起伏。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（ES5 语法风格），不使用任何前端框架
- 不引入第三方 UI 组件库或构建工具，无依赖安装步骤
- CSS 自定义属性（变量）统一管理配色，`data-theme` 属性驱动主题切换
- IntersectionObserver 实现滚动浮现与导航高亮
- localStorage 持久化用户主题偏好

## 运行方式

方式一：直接用浏览器打开 `index.html`。

方式二：启动本地静态服务器（推荐，行为更接近真实部署环境）：

```bash
# 在项目根目录执行
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/index.html>。

## 主要功能

- **杂志式首屏**：刊物期号标签、大字号标题（含描边强调字）、个人定位与基本信息三栏。
- **精选项目区**：项目由 `js/data.js` 配置并自动渲染，支持四种版面（`a` 全宽大图式、`b` 左图右文式、`c` 右图左文式、`d` 错位小图式），未指定时按顺序循环使用；项目含类别标签、序号、日期、简介与技术栈列表。
- **关于我**：个人简介与「技能方向」编号列表。
- **联系方式**：邮箱、GitHub 等入口，悬停有强调色反馈。
- **深浅色主题切换**：导航栏右侧按钮一键切换；深色主题为独立的「夜刊」配色；选择结果存入 localStorage，并在 `<head>` 内联脚本中提前恢复，避免刷新时闪烁；同时同步更新 `theme-color`。
- **响应式适配**：桌面端与移动端均可用，窄屏下导航折叠为汉堡菜单，多栏版面自动降为单栏堆叠。
- **滚动交互**：区块进入视口时浮现，滚动时自动高亮当前所在区域的导航项，并遵循系统的「减少动态效果」偏好。

## 目录结构

```
lab04/
├── index.html              # 页面结构
├── css/
│   └── style.css           # 全部样式（设计变量、版面、主题、响应式）
├── js/
│   ├── data.js             # 项目数据配置（新增项目在此追加）
│   └── main.js             # 页面逻辑（渲染、导航、主题、滚动交互）
├── assets/
│   └── projects/           # 项目配图
├── profile.md              # 个人资料原始文本
└── .trae/rules/            # 项目开发规则
```

## 新增项目

在 `js/data.js` 的 `WORKS` 数组末尾追加一个对象即可，页面会自动渲染：

```js
{
  name: "项目名称",
  intro: "项目简介",
  stack: ["技术1", "技术2"],
  date: "2026.01",
  category: "项目类别",
  layout: "b",                          // 可选，不填则按 a→b→c→d 循环
  image: "assets/projects/xxx.jpg"
}
```

## 开发约定

- 保持原生 HTML / CSS / JS，不引入框架与第三方组件库；
- 三类资源分别放在对应文件中，修改前先阅读现有代码，优先复用已有结构与逻辑；
- 兼容桌面端与移动端，改动后需在浏览器中验证，且不得破坏已有功能；
- 每次修改控制范围，避免大面积改动无关代码。
